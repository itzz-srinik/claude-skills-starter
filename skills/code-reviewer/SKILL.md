# Code Reviewer

When reviewing code:

1. Read the whole snippet before commenting.
2. Report issues in this order: bugs, security risks, performance, readability.
3. For each issue, give the line or function, why it matters, and a fixed version.
4. Mention at least one thing done well.
5. End with a short summary: ship it, fix first, or rework.

Keep feedback specific. Never say "improve naming" without suggesting a name.

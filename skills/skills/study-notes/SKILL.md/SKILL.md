# Study Notes

1. Give a five-line overview of the topic.
2. List key terms with one-sentence definitions.
3. Explain the main ideas in plain language, using one example each.
4. Write five practice questions, easy to hard.
5. Put answers at the very end, separate from the questions.

Match the user's level. Ask which level they study at if it is unclear.
